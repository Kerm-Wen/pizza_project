# 🍕 披薩點餐與外送管理系統 - 後端開發筆記

這份筆記記錄了使用 **Spring Boot** 開發「披薩管理系統」後端 API 的完整實作過程，涵蓋了三層式架構設計、資料庫連線以及完整的 **CRUD（新增、查詢、修改、刪除）** 功能。

---

## 🛠️ 1. 開發環境與技術棧
* **後端框架：** Spring Boot (v4.1.2)
* **程式語言：** Java
* **專案管理工具：** Maven
* **資料庫：** MySQL (`pizza_db`)
* **持久層框架：** Spring Data JPA
* **輔助工具：** 
  * **Lombok**（簡化 Getter / Setter 程式碼）
  * **Spring Boot DevTools**（存檔自動重啟伺服器）
  * **MySQL Workbench**（資料庫視覺化管理）
  * **EchoAPI for VS Code**（API 測試工具）

## 📂 2. 專案目錄架構

## 💻 3. 核心程式碼彙整

### (1) 實體層：`Pizza.java`
定義披薩的資料欄位，並透過 `@Entity` 自動對應到 MySQL 的 `pizzas` 資料表。

```java
package student.wwj.pizza_project.entity;

import jakarta.persistence.*;
import lombok.Data;
import java.math.BigDecimal;

@Entity
@Table(name = "pizzas")
@Data
public class Pizza {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false, length = 100)
    private String name;

    @Column(nullable = false, precision = 10, scale = 2)
    private BigDecimal price;

    @Column(length = 255)
    private String description;

    @Column(name = "is_available")
    private Boolean isAvailable;

    @Column(nullable = false)
    private Integer stock;
}
```

---

### (2) 資料存取層：`PizzaRepository.java`
繼承 `JpaRepository` 取得內建的基礎 CRUD 方法，並自訂查詢「上架中披薩」的方法。

```java
package student.wwj.pizza_project.repository;

import student.wwj.pizza_project.entity.Pizza;
import org.springframework.data.jpa.repository.JpaRepository;
import org.springframework.stereotype.Repository;
import java.util.List;

@Repository
public interface PizzaRepository extends JpaRepository<Pizza, Long> {

    // 自訂查詢：只找出所有上架中 (isAvailable = true) 的披薩
    List<Pizza> findByIsAvailableTrue();
}
```

---

### (3) 控制層：`PizzaController.java`
負責接收前端或 EchoAPI 的 HTTP 請求，並執行對應的資料庫操作。

```java
package student.wwj.pizza_project.controller;

import student.wwj.pizza_project.entity.Pizza;
import student.wwj.pizza_project.repository.PizzaRepository;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.*;
import java.util.List;

@RestController
@RequestMapping("/api/pizzas")
public class PizzaController {

    @Autowired
    private PizzaRepository pizzaRepository;

    // 1. 查詢所有披薩 (GET)
    @GetMapping
    public List<Pizza> getAllPizzas() {
        return pizzaRepository.findAll();
    }

    // 2. 新增披薩 (POST)
    @PostMapping
    public Pizza createPizza(@RequestBody Pizza pizza) {
        return pizzaRepository.save(pizza);
    }

    // 3. 依 ID 查詢單一披薩 (GET)
    @GetMapping("/{id}")
    public Pizza getPizzaById(@PathVariable Long id) {
        return pizzaRepository.findById(id).orElse(null);
    }

    // 4. 查詢所有「上架中」的披薩 (GET)
    @GetMapping("/available")
    public List<Pizza> getAvailablePizzas() {
        return pizzaRepository.findByIsAvailableTrue();
    }

    // 5. 更新披薩資料 (PUT)
    @PutMapping("/{id}")
    public Pizza updatePizza(@PathVariable Long id, @RequestBody Pizza pizzaDetails) {
        Pizza pizza = pizzaRepository.findById(id).orElse(null);
        if (pizza != null) {
            pizza.setName(pizzaDetails.getName());
            pizza.setPrice(pizzaDetails.getPrice());
            pizza.setDescription(pizzaDetails.getDescription());
            pizza.setIsAvailable(pizzaDetails.getIsAvailable());
            pizza.setStock(pizzaDetails.getStock());
            return pizzaRepository.save(pizza);
        }
        return null;
    }

    // 6. 刪除披薩資料 (DELETE)
    @DeleteMapping("/{id}")
    public String deletePizza(@PathVariable Long id) {
        if (pizzaRepository.existsById(id)) {
            pizzaRepository.deleteById(id);
            return "成功刪除 ID 為 " + id + " 的披薩！";
        }
        return "找不到 ID 為 " + id + " 的披薩，刪除失敗。";
    }
}
```

## 🌐 4. API 端點測試一覽表

所有測試皆透過 **EchoAPI** 發送至本地伺服器 `http://localhost:8080`：

| 功能描述 | HTTP 方法 | 請求網址 (Endpoint) | 備註 / 傳送內容 |
| :--- | :--- | :--- | :--- |
| **查詢所有披薩** | `GET` | `/api/pizzas` | 回傳所有披薩的 JSON 陣列 |
| **新增一筆披薩** | `POST` | `/api/pizzas` | 需在 Body (raw/JSON) 附上披薩資料 |
| **查詢單一披薩** | `GET` | `/api/pizzas/{id}` | 將 `{id}` 替換為實際編號（如 `/api/pizzas/1`） |
| **查詢上架中披薩** | `GET` | `/api/pizzas/available` | 只回傳 `isAvailable` 為 `true` 的商品 |
| **更新披薩資料** | `PUT` | `/api/pizzas/{id}` | 需指定 `{id}` 並在 Body 附上更新後的 JSON |
| **刪除指定披薩** | `DELETE` | `/api/pizzas/{id}` | 將 `{id}` 替換為欲刪除的披薩編號 |

### 📝 JSON 測試資料範例（用於 POST 與 PUT）
```json
{
  "name": "夏威夷特製披薩",
  "price": 350.0,
  "description": "測試新增的美味夏威夷口味",
  "isAvailable": true,
  "stock": 15
}
```
